Fastest GitHub Pages setup:
1. Create a new PUBLIC GitHub repository named: cds-autofill
2. Upload ALL files from this folder to the repository root.
3. Open repository Settings -> Pages.
4. Under Build and deployment choose: Deploy from a branch.
5. Branch: main ; Folder: / (root) ; Save.
6. Wait for GitHub to publish the site.
7. Your URL will normally be:
   https://YOUR-GITHUB-USERNAME.github.io/cds-autofill/

Use that URL as the Website URL in Lemon Squeezy.
